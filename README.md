# Quiz Game Application

## 📌 Overview
The Quiz Game Application is a responsive web-based quiz built using HTML, CSS, and JavaScript. It presents multiple-choice questions, checks the user's answers, calculates the score, and displays the final result with an option to restart the quiz.

## ✨ Features
- Interactive multiple-choice quiz
- Displays one question at a time
- Instant correct and incorrect answer highlighting
- Automatic score calculation
- Final score display
- Restart Quiz functionality
- Responsive and user-friendly interface

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
